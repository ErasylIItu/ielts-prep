# Сервер ИИ (Cloudflare Worker)

Небольшой сервер-посредник между приложением и Gemini. Ключ Gemini хранится **на сервере в секрете**, поэтому людям, которые открывают приложение, вводить свой ключ не нужно.

```
Приложение (GitHub Pages)  →  Worker (твой ключ в секрете)  →  Google Gemini
```

## Защита
- **CORS:** браузеры могут обращаться к серверу только с адресов из `ALLOWED_ORIGINS` (твой сайт на GitHub Pages и localhost).
- **Только Gemini:** пропускается только `generateContent` для моделей `gemini-…`.
- **Лимит:** 20 запросов в минуту с одного IP (встроенный rate limiter Cloudflare и запасной счётчик в памяти).
- **Размер запроса:** до 120 КБ.
- **Код доступа (по желанию):** если задать секрет `ACCESS_CODE`, ИИ будет работать только у тех, кто ввёл этот код в настройках приложения.
- Ключ никогда не возвращается в ответах, а тексты запросов не записываются в логи.

Важно: все пользователи расходуют **лимиты твоего ключа** Gemini. На бесплатном тарифе это ограниченное число запросов в минуту и в день. Если лимит закончится, у всех появится сообщение «AI limit reached». Если друзей много, включи код доступа или платный тариф в Google AI Studio.

## Запуск (один раз, ~10 минут)

Нужен бесплатный аккаунт Cloudflare: https://dash.cloudflare.com/sign-up

В терминале VS Code, из папки `server`:

```bash
cd server
```
```bash
npx wrangler login
```
Откроется браузер: войди в Cloudflare и нажми **Allow**.

```bash
npx wrangler deploy
```
В конце появится адрес вида `https://ielts-prep-ai.<имя>.workers.dev`. Скопируй его.

```bash
npx wrangler secret put GEMINI_KEY
```
Вставь свой ключ Gemini, когда терминал попросит (символы не отображаются), и нажми Enter.

По желанию, код доступа:
```bash
npx wrangler secret put ACCESS_CODE
```

Проверка: открой `https://ielts-prep-ai.<имя>.workers.dev/health`. Должно быть `"configured":true`.

## Подключить сервер к приложению
1. В файле `js/config.js` впиши адрес: `export const AI_PROXY_URL = 'https://ielts-prep-ai.<имя>.workers.dev';`
2. В `sw.js` подними `VERSION`.
3. Залей на GitHub (`git add -A`, `git commit -m "Connect AI server"`, `git push`).

После этого в настройках приложения появится «ИИ работает через сервер приложения», и ключ никому не понадобится. Свой ключ по-прежнему можно ввести в «Свой ключ Gemini (необязательно)»: тогда запросы пойдут напрямую в Google.

## Если адрес сайта другой
Добавь его в `ALLOWED_ORIGINS` в `wrangler.toml` и снова выполни `npx wrangler deploy`.
